Oral Cancer Detection using Deep Learning

This project implements a deep learning model to detect oral cancer from medical images. The model combines Convolutional Neural Networks (CNN) with Graph Signal Processing (GSP) techniques to improve feature representation and classification performance.

Features

Image-based oral cancer detection

Hybrid architecture using CNN + Graph Signal Processing

Uses adjacency matrices to capture relational features

Optimized with AdamW optimizer

Achieved ~85% test accuracy on the Kaggle oral cancer dataset

Tech Stack

Python

TensorFlow / Keras

NumPy

OpenCV

Matplotlib

Dataset

The model was trained on the Kaggle Oral Cancer Dataset, containing labeled medical images for cancer detection.

Model Overview

Image preprocessing and normalization

Feature extraction using CNN layers

Graph-based representation using adjacency matrices

Classification with optimized deep learning layers

Results

Test Accuracy: 85%

Demonstrates the effectiveness of combining CNN with Graph Signal Processing for medical image classification.
